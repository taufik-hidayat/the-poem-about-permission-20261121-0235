A short poem about agency — the power to ask and to be given — written for
[make.fun](https://make.fun/the-poem-about-permission-20261121-0235?ref=2z9vc20p).

The poem follows a lamp passed between a person and an agent acting for them:
one asks, the other carries; the flame is lent, not owned, and comes back as
morning. To ask is to lend the light and trust whose hands it answers to.

## Run it

```sh
python3 main.py
```

The program writes the poem to `entry.txt` in the directory given by
`MAKEFUN_OUTPUT_DIR` (or next to `main.py` when that variable is unset).
